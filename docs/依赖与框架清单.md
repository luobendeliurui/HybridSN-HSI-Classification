## 九、三点结论

### 1. 本次仿真只依赖一个深度学习框架：PyTorch

论文原作者的实现基于 **Keras / TensorFlow**，本实验采用 **PyTorch 重实现**（`Pancakerr/HybridSN`）。
因此"深度学习框架"这一层非常干净，只有 **PyTorch + torchvision + torchinfo** 三个包。

### 2. 不需要单独安装 CUDA Toolkit

`CUDA 13.0` 与 `cuDNN 91200` 均由 **PyTorch 的 wheel 自带**，安装 PyTorch 时一并就位，
无需前往 NVIDIA 官网下载 CUDA 安装包。这是初学者最常见的误解之一。

### 3. 环境共 143 个包，但项目只需要 11 个

这解释了**为什么不能直接 `pip freeze > requirements.txt`**：
那样会导出 143 行，其中 132 个与项目无关。
因此 `requirements.txt` 采用**挑选顶层依赖 + 锁定版本 + 补充关键间接依赖**的方式编写。
