# ============================================================================
#  版本选择说明（与原仓库 README 要求的差异及原因）
# ----------------------------------------------------------------------------
#  原仓库 README 要求: pytorch 1.9.0 / scikit-learn 1.0.2 / spectral 0.22.2
#                      / torchinfo 1.6.1
#
#  [torch] 1.9.0 → 2.10.0   （两条原因，缺一不可）
#    1) PyTorch 1.9.0 在 PyPI 上只发布到 cp39 的 wheel，本机 Python 为 3.10，
#       没有对应安装包；
#    2) 1.9.0 自带的 CUDA 为 10.2 / 11.1，不支持 RTX 5060 的 sm_120
#       (Blackwell) 计算架构 —— 即使装上也无法调用 GPU。
#       sm_120 需要 CUDA 12.8 及以上，故必须使用高版本。
#    → 实测结果: torch.cuda.is_available() == True，
#                设备 "NVIDIA GeForce RTX 5060"，算力 (12, 0)。
#
#  [spectral] 0.22.2 → 0.22.4
#    0.22.2 在 PyPI 上仅发布源码包 (tar.gz)，Windows 下编译需要 MSVC 编译器
#    （本机未安装任何 C 编译器）。0.22.3 / 0.22.4 提供纯 Python wheel
#    (py3-none-any)，且 notebook 使用到的 API（imshow / save_rgb /
#    spy_colors / view_cube）与 0.22.2 完全一致，代码无需任何修改。
#
#  [scikit-learn] 1.0.2 → 1.7.2  /  [torchinfo] 1.6.1 → 1.8.0
#    满足"版本不低于原要求"，且对 PyTorch 2.x 的兼容性更好。
#
#  网络提示（本机实测）
#    若 pip 报 ProxyError / SSLError，说明 pip 未正确使用系统代理，
#    可显式指定（本机代理端口 7897）:
#        pip install -r requirements.txt --proxy http://127.0.0.1:7897
